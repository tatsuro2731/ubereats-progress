# v89 リッチの全面刷新

## 変更

- リッチに独自配色を導入（ライト：パール地にエメラルド→ティール→スカイ、ダーク：インク地に発光するミントとシアン）。クラシックは無変更。
- 素材：半透明ガラスのカード、差し色グラデーションの縁（メインカード）、状態色を透かす操作エリア、グラデーション文字の件数。
- 動き：オーロラ背景、起動時の立ち上がり、稼働中の脈動・走る光・呼吸、進捗バー、件数変更時の弾みと発光、タブのフェード、押下の縮み。`appearance.js` はクラスの付け外しだけを担当し、動きの定義は `rich.css` に置く。
- 起動アニメーション終了後にカードの収まりを測り直す（移動中の位置で密度を決めないため）。

## 確認

- `npm run verify`（268件）と `git diff --check`。rich.css の検査は「実要素にレイアウト指定がない」「すべてリッチ限定」「アニメーションは視差効果オフ時のみ」「状態色がライト・ダーク両方に定義済み」に更新。
- Chrome（Playwright、テスト用の空データ）で 4画面幅 × ライト／ダーク × 開始前／稼働中／休憩中の24通り、主要19要素の位置と大きさがクラシックと一致。コンパクト版も一致。
- 動き：起動時に r-intro が付き終了後に外れること、＋1件で r-tick が付き約0.8秒で外れること、連打後も残らないこと、タブ切替中に操作エリアが動かないこと、「視差効果を減らす」ではアニメーションが0件であること、クラシックではアニメーションが0件であること。
- 操作：件数増減、時間ON/OFF、±1分、ペース切替、設定の開閉（×・背景・完了）、テーマ切替、スタイル切替、コンパクト版との相互同期、再読み込み後の保持、クエスト登録フォーム。
- 主要な文字色と背景のコントラスト比を計算（最小4.36、太字の大きな文字。本文は5.4以上）。
- 未確認：実機Safariでの描画負荷（オーロラ＋すりガラス）、電池への影響、グラデーション文字とマスク枠の描画、カード並べ替えのドラッグ、設定の下スワイプ閉じ。
