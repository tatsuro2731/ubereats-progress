# v87 クエスト画像読み取りのエラー表示

## 変更

- 通信や時間切れで失敗したとき、「同じ画像でもう一度読み取る」ボタンを表示。画像を選び直さずに再試行できる。
- 画像自体が原因の失敗（形式・20MB超・開けない・大きすぎる）は `fileProblem` として区別し、再試行ボタンを出さない。
- 読み取れた結果への注意（2回の結果が不一致など）は失敗と同じ赤字をやめ、通常の案内として表示。失敗は赤い枠で表示。
- 準備が12秒を超えたら「中止して手入力もできます」と案内（従来は最長30〜90秒、同じ文言のまま）。
- 開けない画像の文言を、選択できる形式（PNG・JPEG・WebP）に合わせた。

読み取りロジック・保存キー・保存形式は変更なし。

## 確認

- `npm run verify`（再試行の回帰テストを追加、266件）と `git diff --check`。
- Chrome（Playwright、テスト用の空データ）で操作：CDN遮断→失敗表示→再試行ボタン→応答なしの状態で12秒後の案内→中止、壊れた画像・HEIC・21MBで再試行ボタンが出ないこと、フォームを閉じて開き直すと表示が消えること。注意表示と失敗表示は読み取り結果を差し替えて 320・393・440px、ライト／ダークで確認。主要操作（件数、時間ON/OFF、設定開閉、同期）も再確認。
- 未確認：実際のOCR（この環境からCDNへ届かないため）での成功・再試行成功、実機Safari。
