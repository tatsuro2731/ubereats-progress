# v69 読み取り失敗への対策

利用者のiPhoneで候補0件のエラーが発生。表示されたエラーからOCR終了後の候補判定で失敗したと分かるが、当該端末の認識文字はまだ取得できておらず、具体的な原因は未確定。

## 変更

- 不要な拡大をやめ、最大1600px幅・600万画素以内で元の画素を維持。
- 進捗分数が読めればタイトル誤認でも進捗として判定。円記号のY・羊、期間の長音ダッシュ、時刻の余分な句読点を正規化。金額の桁や累計の整合検査は保持。
- 高さが異なる左右の文字列を、上下の重なりも使って同じ行に組み直す。
- 組み直し失敗時はOCR本来の行順も試す。候補・期間が読めない場合は元の色で再試行し、先に読めた候補は保持する。
- 日本語認識データのキャッシュをこのアプリ用に分離。
- 読み取り版・処理画像サイズ・認識文字を端末内に表示。自動送信・永続保存は行わず、再選択やフォーム終了で消去。

## 確認

元の2画像で期間・全段階・進捗9件を確認。新規登録・同一期間編集・今日分の入力必須・失敗後の保存を非描画DOMで確認。172件の自動テストと差分検査を実施。

Cloud browserのURLポリシー拒否があるため、iPhoneの症状の再現・解消や実画面操作は未確認。修正で解決したと断定しない。再発時は新しい認識結果表示から調査する。
