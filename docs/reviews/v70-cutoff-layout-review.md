# v70 期間締切と見切れ対策のレビュー

## 依頼と修正

- クエストの終了を「03:59まで」と表示・入力する。内部は従来の04:00未満のままで、03:59:59.999を含み、04:00は次の期間へ集計する。
- OCRの04:00終了からフォームへの変換、登録済み期間の表示、ひな形、編集・保存の往復を揃える。すでに03:59と書かれた画像は再度1分引かない。
- 完了件数、増減ボタン、達成率をカード内のスクロール領域の外へ移動する。スクロール位置によって「完了件数」ラベルが切れる構造をなくす。下部の目標ペースも従来どおり外側に保つ。
- 440px以下ではクエストの日時欄を縦1列にし、iOSのネイティブ日付欄の横幅を確保する。

## 保存・影響範囲

- 既存のlocalStorageキー、保存形式、期間終了の包含規則は変更しない。データ移行は行わない。
- 日時欄が未変更なら元の秒・ミリ秒まで保持し、期間変更として件数補正を要求しない。件数補正・売上・稼働日・未知の保存項目を保持する。
- 12時間カウント、終了上限の任意時刻、休憩、他社稼働、履歴の計算には変更しない。通常版・コンパクト版の同期を維持する。
- ヘッダー、目標ペース、クエスト要約、小カードを実測高さ予算に含める。最低高さも収まらない画面ではページ全体のスクロールと固定操作エリア分の下余白を保つ。
- HTML参照、Service Worker登録、キャッシュ・アセット、OCRの診断表示をv70に揃える。
