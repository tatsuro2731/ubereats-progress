# v92 リッチ：余白・文字サイズ・太さの見直し

実機スクリーンショット（4枚表示、tight）と計測値をもとに全体のバランスを確認した。

## 直したもの

- カード間隔：メインカード→小カード 6px、小カード同士 6px は、影と丸みのあるリッチでは重なって見える。tight で 10px／8px に。
- メインカード内：目安の枠（高さ42px、余白3px）と下の補足行（間隔2px）がくっついていた。枠を46px、間隔を6pxに。
- 太さ：補助ボタン（一時停止、±1分、他社稼働）と題名が900で、数値（750〜800）より強かった。700／800に。
- 上端：ステータスバーの帯（単色）の直下からオーロラが始まり、境目が線に見えていた。上端84pxを地色へなじませた。

## 問題なしと判断したもの

- 文字サイズの段階：件数34→余裕30→残り時間26→小カード値24→目安19、補足12〜14。主従は付いている。
- 下の操作エリアの余白と行間。

## 見送ったもの

- 小カードの横余白拡大：4枚でも稼働率の補足が折り返してカードが17px伸びる。
- dense・compact での間隔拡大：余りが数pxしかなく、詰め方が一段きつくなる。

## 確認

- `npm run verify`（268件）、`git diff --check`。
- Chrome（Playwright）で5サイズ×4枚／6枚：詰め方の段階がクラシックと同じ、折り返しなし、横はみ出しなし。主要操作を再確認。
- 未確認：実機Safari。tightで画面にちょうど収まっていた端末では、下段の小カードが操作エリアに最大14px掛かる可能性がある。
