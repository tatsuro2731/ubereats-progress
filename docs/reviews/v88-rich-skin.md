# v88 リッチスタイルの追加

## 変更

- 設定に「見た目のスタイル」（リッチ／クラシック）を追加。初期値はリッチ。コンパクト版にも同じ切替を追加。
- `styles/rich.css` を新設。クラシックのCSSには手を入れず、`html[data-skin="rich"]` のときだけ質感を重ねる。接頭辞を `:where()` にして詳細度を上げず、クラシックの状態別ルール（押下中、並べ替え中など）をそのまま生かす。
- 保存は新キー `ubereatsProgressSkinV1`。既存キーと形式は変更なし。バックアップは接頭辞一致のため自動で含まれる。
- 修正：`[data-theme-mode]` が `<html>` 自身にも一致し、画面のどこをタップしてもテーマ設定を同じ値で書き直していた。ボタンだけに限定。
