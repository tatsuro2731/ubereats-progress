# v95 リッチ：アイコンタイルの色を揃える

## 指摘

実機（開始前、4枚表示）で「必要ペースのアイコンだけ強調されているのは意図があるか」。

## 原因

v94で、値がまだ出ていないカードのタイルを灰色にしていた。開始前は「必要ペース」だけ値があるため、1枚だけ色付きになった。「値が出たカードが点灯する」という意図だったが、説明なしでは伝わらず、特定のカードの強調に見える。

## 対応

- タイルは常に差し色にする。計測前は値の文字の薄さだけで示す。

## 確認

- `npm run verify`、`git diff --check`。
- Chrome（Playwright）で開始前・稼働中をライト／ダークで目視。4枚のタイルが同じ色であること、計測前の値が薄いままであることを確認。
- 未確認：実機Safari。
