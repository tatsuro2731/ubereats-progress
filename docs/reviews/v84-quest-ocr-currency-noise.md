# v84 進捗画面の誤読補正

## 再現
11/6の1320×2868画像、読み取りv83の4結果をv83の `parseText` に入力していずれも候補0件。
結果1は期間、0/120、17,230円、追加10件・2,260円を含むが、
追加報酬の円記号が「+\\ ギ 2,260」と認識されると
既存パーサは金額と認めず、保留の追加段階により全体を除外する。

## 修正

数字の推測・追加段階の自動生成・別OCR出力の不整合な段階合成は行わない。
期間、件数、報酬、保存形式、タイマー、通常版・コンパクト版の動作は変更しない。
HTML・JavaScript・Service Workerのキャッシュ版を84に統一した。
