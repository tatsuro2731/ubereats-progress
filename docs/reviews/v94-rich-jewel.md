# v94 リッチ：宝石面のメインカードと演出

## 依頼

「もっとリッチ感を増して欲しい」。v93までのリッチは、ライトでは白いカードが並ぶ印象で、主役がなかった。

## 変更

- メインカードを濃い色の面に変更（順調＝エメラルド、遅れ＝ブロンズ、大幅遅れ＝深紅）。粒子・細線・艶・金属調の縁を重ねた。カード内だけ配色トークンを明色へ差し替え、文字とアイコンを面に合わせた。
- ＋を面から最も浮く明るいボタンに、−を磨りガラスに。進捗バーは暗い溝に光るバー。
- 小カードと設定見出しのアイコンを差し色のタイルに。小カードの面の隅に淡い色。
- 操作エリアに状態色の光、稼働ボタンに艶。題名に差し色のにじみ。
- 演出：件数増加時の輪と光の粒、数字の入り方、面を横切る光、目標達成時の金色と紙吹雪。
- 修正：件数変化の合図をクラスから`data-`属性へ。本体が描画のたびに`#hero`の`class`を書き直すため、従来の`r-tick`は次の描画（最長1秒後）で消され、演出が途中で切れることがあった。

## 確認

- `npm run verify`（268件）、`git diff --check`。rich.css の検査を更新（カード内トークンの定義、状態ごとの面、`position: relative`の許可）。
- 文字の読みやすさ：ライト／ダーク × 順調／遅れ／大幅遅れ／達成の8通りで、メインカード内の全148の文字について、実際に描画した面の色に対するコントラスト比を計測。小さい文字は4.5以上、大きい文字は3以上（最も明るい画素に対して）。例外は−ボタンの記号で、ボタン枠の縁の明るい画素を拾った値が2.7〜2.9、記号の下の面に対しては5.0以上。
  - 当初案は左上に艶を置いており「完了件数」などが2.9〜3.9だった。面を一段深くし、艶を右上へ移して解消。
- 位置と大きさ：5サイズ × 4枚／6枚で、詰め方の段階・メインカード高・小カード高・折り返しがv93と同じ。横はみ出しなし。
- 動き：合図の属性が付いて外れること、連打後に残らないこと、常時くり返す動きが transform・opacity・filter だけであること、「視差効果を減らす」ではアニメーション0件・紙吹雪なし、タブ切替で操作エリアが動かないこと、面を横切る光がカード外へ出ないこと。
- 達成：その場で達成→金色＋紙吹雪（キャンバスは約3秒で消える）、再起動時は金色のみ、件数を戻すと解除。
- 主要操作、スタイル切替、コンパクト版との同期、再読み込み後の保持、保存キー不変。クラシックに変化がないこと。
- 目視：ライト／ダークの各状態、休憩中、4枚表示、320px幅、設定、コンパクト版。
