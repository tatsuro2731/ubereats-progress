# v65 目標ペースの見切れ修正

## 原因と変更

クエスト要約のある進捗画面で、小カードを下部固定操作エリアの上に収める高さ制限が、メインカード末尾の目標ペースにもかかっていた。

- 高さ制限とスクロールの対象をメインカード内の詳細部分に限定した。目標ペースは同じカードの下部に置き、スクロール領域の外で表示する。
- 小カードの下端が利用可能な高さを超えた分だけ詳細部分を縮める。目標ペース、カードの枠、余白も実測値に含める。
- クエスト要約の表示・折り返しによる高さの変化も監視する。
- HTML、配信URL、Service Workerの版番号を65に統一した。

## レビュー

目標ペースの要素IDとタップ操作は維持している。通常版・コンパクト版の計算、時計、保存形式、履歴、クエスト件数の記録処理には変更を加えていない。コンパクト版とメイン画面のJavaScriptの差分は配信URLの版番号のみ。

## 実施した検証

- `npm run verify`: JavaScript構文確認と148件のテストが成功。
- 追加テストで、目標ペースの表示行の高さを28px・52pxとした場合の小カード領域確保、およびクエスト要約の表示・折り返し時の再計算を確認した。これらは矩形の模擬値による計算検証であり、ブラウザー描画確認ではない。
- HTMLパーサーでタグの対応、目標ペースがスクロール領域外かつメインカード内にあること、小カードがメインカードの後にあることを確認した。
- `git diff --check`: 成功。

## 未確認の範囲

検証用ブラウザーではタブ一覧・ページ表示の接続がタイムアウトし、復旧処理後も操作できなかった。開発サーバーは起動できたが、クリック・入力・スクロールなどの画面操作確認には到達していない。

320px・393px・430〜440px幅での実描画、iPhoneのSafari/PWAとセーフエリア、PWAの更新・オフライン動作は未確認。自動テストの成功と画面操作の成功を同一視しない。ユーザーの継続指示である確認なしでの反映方針に従い、この制約を報告したうえで公開する。
