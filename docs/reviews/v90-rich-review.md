# v90 リッチ（v89）のレビューと修正

## 指摘と対応

1. **常時動く演出が再描画を伴っていた（重要度：高、実機未計測）**
   進捗バーの光（background-position）、操作エリア上端の光（background-position）、状態ランプ（box-shadow）は、稼働中ずっと毎フレーム描き直す作りだった。12時間使う画面には不向き。
   → 進捗バーの光は件数が変わった瞬間だけに変更。上端の光と状態ランプは transform と opacity だけで動かす形に作り替え。常時動くのは transform・opacity・filter のみになった。テストで固定。
2. **遅れ・大幅遅れでもメインカードの縁が緑〜青のままだった（中）**
   数字は橙・赤になるが、いちばん目立つ縁の光が「順調」の色のままで、状態の見分けを弱めていた。
   → 遅れ＝橙、大幅遅れ＝赤の縁に変更。
3. **起動アニメーションの終了検知が、途中でカードが描き直されると失敗しうる（低）**
   描き直されたカードの終了イベントは届かないため、r-intro が残り、以後カードが描き直されるたびに立ち上がりが再生される可能性があった。
   → 操作エリア（描き直されない）が最後に終わるよう時間を調整し、その終了でも解除する。
4. **ライトとダークでトークンの定義漏れを検知するテストがなかった（低）**
   → 両ブロックのトークン集合が一致することをテストに追加。現状は漏れなし。

## 問題なしと確認したもの

- 再起動時、復元された件数で数字の弾みが誤発火しない。
- スタイルは初回描画前に適用される（appearance.js は head で同期読み込み）。クラシックの一瞬表示は起きない。
- 遅れ・大幅遅れ、スクロール下部（稼働計測）、設定下部の配色と可読性（ライト／ダーク）。
- 24通りの位置・大きさ一致、主要操作、同期、保存キー不変。

## 残る未確認

- 実機Safariでの負荷と電池。背景のオーロラ2枚（大きな合成レイヤー）と、その上のすりガラスは毎フレーム合成される。重ければ、オーロラを静止させるのが最も効く。
- グラデーション文字と縁のマスク描画（Safari）、カード並べ替えのドラッグ、設定の下スワイプ閉じ。
