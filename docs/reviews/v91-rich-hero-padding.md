# v91 リッチ：メインカードの内側余白

## 変更

- 実機のスクリーンショットで、メインカードの「完了件数」付近が枠に寄って窮屈に見えるとの指摘。最も詰めた段階では余白が縦6px・横10pxで、角丸24pxの内側に文字が入り込んでいた。
- リッチのみ、メインカードの内側余白を拡大：横 clamp(12px, 22vw − 70.5px, 16px)、縦は compact 12px／dense 9px／tight 12px。
- スタイル切替時にカードの収まりを測り直す。
- クラシックは無変更。

## 確認

- `npm run verify`、`git diff --check`。
- Chrome（Playwright、テスト用の空データ）で 395×773（実機のセーフエリアを除いた相当）・393×852・375×667・320×568・440×956 × 4枚／6枚：詰め方の段階がクラシックと同じこと、シングル・ダブルの目安と小カードの高さが変わらない（折り返しが起きない）こと、横はみ出しなしを計測。
- 小カードの横余白も試したが、6枚表示で文字が折り返してカードが17px伸び、操作エリアに掛かったため取りやめた。
