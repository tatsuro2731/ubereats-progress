# v93 リッチ：上端のなじませ位置の修正

## 症状

実機（iPhone、ホーム画面のアプリ、リッチ・ライト）で、ステータスバーの帯（単色 `#edf2f5`）の下端にオーロラ背景との境目がくっきり残っていた。v92 の「上端84pxを地色へなじませる」が効いていなかった。

## 原因

スクリーンショット（1320×2868、3倍）の色を縦に読んだ結果：

- 0〜185px（62pt＝セーフエリア上端）は単色の帯。
- 186pxで `#c7ece2` へ段差。そこから約252px（84pt）まで、わずかに濃くなるだけ。

ページは画面の最上端から始まり、帯はその上に重なっている。v92 のなじませは最上端（0px）から84pxだったため、62ptぶんは帯の下に隠れ、帯の下端では地色が約26%しか残っていなかった。

## 直したもの

- `styles/rich.css`：なじませをセーフエリア上端から始める。0〜セーフエリア上端は地色、そこから84pxで透明へ。セーフエリアが0の環境ではv92と同じ見た目。

## 確認

- 自動テスト（check・test）。
- ブラウザーでの再現確認：セーフエリアを62pxに置き換えた複製で、帯の下端から滑らかにつながることを確認。
- 実機確認は未実施（反映後にユーザーの端末で確認が必要）。
