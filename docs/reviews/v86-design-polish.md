# v86 デザイン仕上げ

## 変更

- 小カード：計測前の文言（計測待ち・未開始）を控えめな色と太さにし、実測値と区別。
- 小カード：ペース切替アイコンをカード右下へ移し、数値の高さを他カードと揃えた。
- 終了予測カードの補足を文節で折り返し、1文字だけの行をなくした。説明文全般に文節折り返しを指定（未対応ブラウザーは従来どおり）。
- ヘッダーの基準タグを320px幅でも1行に収めた。
- 設定：使用頻度順に「進捗設定 → 小カード表示 → 並び替え → 画面の明るさ → バックアップ」へ並べ替え。
- 設定：切替時刻は「自動」のときだけ表示し、固定時は補足文を「◯◯で固定しています」に変更。
- クエスト未登録時、重複していた「新しく登録」ボタンを隠した。

操作位置（＋／−、残り時間補正、時間ON/OFF）と保存キー・保存形式は変更なし。

## 確認

- `npm run verify`（265件）と `git diff --check`。
- Chrome（Playwright、テスト用の空データ）で 320×568・393×852・440×956 を操作：件数増減、時間ON/OFF、±1分、ペース切替、設定の開閉（×・背景・完了）、テーマ切替、目標変更、クエスト登録フォーム開閉、コンパクト版との同期、再読み込み後の保持。小カード下端が固定操作エリアに重ならないこと、横はみ出しなしを計測。
- 未確認：実機Safari（文節折り返しの効き方、セーフエリア、PWA更新）、下スワイプで設定を閉じる操作、カード並べ替えのドラッグ。
